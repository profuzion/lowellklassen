# Lowell Klassen

Personal site for Lowell Klassen. Next.js, React, TypeScript, and Tailwind CSS.

## Run

```bash
corepack pnpm install
corepack pnpm dev
```

Open http://localhost:3000.

```bash
corepack pnpm build
corepack pnpm start
```

Checkout for the existing workbook and audit offers stays at `/checkout`. It needs Stripe keys from `.env.example` before payment can open.
